# PXTools Patterns — for KB Editor

Editor support for the **PXTools** family of GeneXus patterns inside KB Editor.

- **Provider:** PuntoExe
- **Pattern types:** PXWorkWith, PXParameterRequest, PXComposer, PXOAV, PXFlowController,
  PXEntityParameters, PXReportTemplate, PXWSData, PXWSLayer, PXWSQuery, PXWSTransaction,
  PXAudit, and more.
- **Requires:** KB Editor (`kbbridge.genexus-visual-editor`)

## What it adds

First-class editing for PXTools pattern instances: dynamic custom-type dropdowns, custom node
captions, context commands, and variable autocomplete in embedded code — across the PXTools
pattern catalog.

## Install

1. Install **KB Editor** first.
2. Download `pxtools-patterns-<version>.vsix` from the [latest Release](../../../releases)
  .
3. **Extensions ▸ … ▸ Install from VSIX…**, then **Reload Window**.
4. Open a PXTools `.gxPattern` instance.

## Distribution
